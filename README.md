# UC3M

Un lugar para almacenar todos mis recursos de la carrera de **ingeniería informática en la
UC3M**: apuntes, prácticas, proyectos y más.

Cuatro años de cosas, así que la calidad varía bastante entre lo de primero y lo de tercero.
Dudo que las prácticas sean las mismas que las tuyas, pero igual te son de ayuda ;D

### 3º

- **[AA — Aprendizaje Automático](Proyectos%20y%20practicas/3º/AA)**
  - [Práctica 1](Proyectos%20y%20practicas/3º/AA/Practica%201%20AA) — predicción de producción eólica (regresión, selección de modelo, HPO)

- **[Criptografía](Proyectos%20y%20practicas/3º/Criptografia_2023-24)** — sistema de cifrado,
  firma y almacenamiento seguro de imágenes con áreas cifradas
- **[PL — Procesadores del Lenguaje](Proyectos%20y%20practicas/3º/PL)**
  - [Práctica 1](Proyectos%20y%20practicas/3º/PL/Practica-1-PL) — analizador de AJSON
  - [Práctica final](Proyectos%20y%20practicas/3º/PL/PL-Practica-Final-AJS) — compilador de AJS (AlmostJavaScript)
- **[SSDD — Sistemas Distribuidos](Proyectos%20y%20practicas/3º/SSDD)**
  - [Proyecto](Proyectos%20y%20practicas/3º/SSDD/Proyecto-SSDD/Proyecto-SSDD-main) — sistema P2P
    de distribución de ficheros tipo torrent, con servidor concurrente en C, cliente en Python,
    servicio web y RPC
  - [Ejercicios 1, 2 y 3](Proyectos%20y%20practicas/3º/SSDD) — sockets, colas de mensajes y RPCs
- **[SSIIUU — Sistemas Interactivos y Ubicuos](Proyectos%20y%20practicas/3º/SSIIUU)**
  - [Prototipado](Proyectos%20y%20practicas/3º/SSIIUU/SSIIUU-Prototipado) — aplicación de compra
    ubicua en gran superficie, con cámara, ubicación y NFC desde el móvil
  - [Lab 1 — Inemuri](Proyectos%20y%20practicas/3º/SSIIUU/Lab1-Inemuri-main) — despertador por
    geolocalización, con radio de acción configurable y feedback háptico
  - [Lab 2 — TODO](Proyectos%20y%20practicas/3º/SSIIUU/Lab2-TODO-main)
- **[UI — Interfaces de Usuario](Proyectos%20y%20practicas/3º/UI/UI-Practica-2-main)** — web de
